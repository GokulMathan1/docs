A preview of upcoming events appears on your **Home** screen. Tap **Show All** to open the full Events browsing screen — or get there anytime from **More → Events & Tickets**.

## Filter and Search

On the full Events screen, narrow the list by:

- **Category**
- **Date**
- **Online** or **Offline**
- **Paid** or **Free**

Or tap **Search** and type an event name to find something specific.

## Event Detail Page

Tap any event to see:

- Who's **organizing** it
- The **date**
- The **agenda**
- **Location** — a **meet link** for online events, or a **map** for offline events
- An **overview** of the event

## Attendee Connections

Some events let attendees add each other as contacts straight from the attendee list — this is a setting the organizer controls for their event. See [Adding Contacts](/contacts/adding-contacts) for how the Event Attendees flow works once it's enabled.

## Creating an Event

Event creation isn't part of the mobile app. Organizers set up and publish events from [myeventjar.com](myeventjar.com)— they need an organizer account with an active subscription before an event can go live and be booked from the app.
